# 商战 · X成长院（联网版）

此版本用于主办方和助教协作，学员只是人员资料，不需要登录。网站入口公开；活动数据和操作必须通过网站自己的账号、密码验证，不依赖 ChatGPT 账号。

## 正式使用

1. 主办方使用私密启用码创建账号，自行设置密码，再创建第一期活动。启用码不会写入网页或公开源码。
2. 创建公司及学员，在公司页面直接编辑名称、备注、成员和老板／财务管理／员工职位。
3. 最高权限主办方在「设置 → 账号管理」直接添加助教账号、初始密码，可停用、启用或重置密码。普通助教看不到这个区域，服务器也拒绝这些操作。也可生成单人邀请码让助教自行注册。
4. 助教登记学员收入、支出，主办方审批；主办方可直接入账。
5. 主办方在设置推进七天进度，第七天处理完申报后结算。

右上角只有一个账号菜单，身份由服务器验证后的账号自动识别，不能手动切换主办方／助教。双方均可从账号菜单开启只读大屏，展示七天进度、公司和学员排名，自动同步；大屏没有登记、修改或底部导航，退出后回到原页面，不改变账号权限。底部固定主页、收益登记、学员登记、设置。学员登记采用卡片和个人七天图表，手机与电脑均可使用。

首次启用表单预填主办方用户名 `preview_admin`，密码仍由主办方自行设置（至少 10 位），没有预置正式密码或公开默认管理员。

## 数据

服务器 D1 数据库是唯一数据来源，浏览器仅保存深浅色偏好。关闭网页、换设备、退出再登录不会初始化活动；其他浏览器以同一账号登录可继续查看。公司资金按当前在册成员的个人余额求和，调动成员会改变公司资金，个人历史流水不删除。

所有金额按整数分存储。多人修改采用版本检查，陈旧页面不能直接覆盖最新数据；收支提交带幂等标识，重试不重复入账。结算保存快照，之后锁定收支和人员；主办方可明确重新开放。

「初始化 · 开启新活动」新建空白活动，上一期仍留在服务器，可从设置导出 JSON。建议每天导出备份；服务器持久化不代表永不丢失或自动外部备份。已启用助教账号继续保留，停用账号不会自动恢复。

## 登录安全

密码使用每账号随机盐、PBKDF2-SHA256 100,000 次和独立服务器密钥处理，不存明文密码。会话令牌仅以摘要存入数据库，浏览器使用 Secure、HttpOnly、SameSite Cookie。登录、注册限频，写操作检查同源，权限在服务器逐次校验。此版本不是经第三方安全认证的身份平台，请使用独立强密码，不要复用邮箱或银行卡密码。

`OWNER_SETUP_KEY`、`PASSWORD_PEPPER` 通过 Sites 服务器密钥配置。不得提交到 GitHub，不得改变 PASSWORD_PEPPER，否则现有密码无法验证。

## 本地开发

需要 Node.js 22.13+（本地测试与预览使用 Node.js 内建 SQLite，建议当前 Node.js 版本）。

```sh
npm install
npm run db:generate
npm test
npm run dev
npm run build
```

预览运行于 `http://127.0.0.1:4187`，仅监听本机。预览主办方账号 `preview_admin`，密码 `Preview_12345!`，只连接隔离的内存测试数据库，不是正式账号。测试示例不会写入正式数据库。正式账号由用户启用。

## 源码

- `public/`：网页、主题、移动布局、图形化学员界面。
- `src/worker.mjs`：服务器接口与权限。
- `src/auth.mjs`：账号密码、会话与限频。
- `src/domain.mjs`：金额和结算规则。
- `db/schema.ts`、`drizzle/`：数据库模型与不可变迁移。
- `scripts/`：构建和隔离本地预览。
- `tests/`：登录权限、多人修改、退出登录持久化、审批和结算测试。

联网版本不能通过双击 HTML 独立使用，必须部署服务器和数据库。旧的「商战指挥台_设置版.html」是单独保留的本地演示版，不会自动获得联网能力。
