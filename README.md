# 商战 · 现场指挥台

## 新增：商战 · X成长院（真实联网版）

**正式网站：[商战 · X成长院](https://business-war-command-zhang.peppy-hare-3360.chatgpt.site)。手机浏览器直接打开即可。**

完整联网源码位于 [`online/`](online/README.md)，包含服务器、数据库迁移、账号权限与手机界面。

- 网站自己的账号和密码，无需 ChatGPT 账号。
- 最高权限主办方可添加、停用、启用助教账号或重置密码；普通助教看不到账号管理，服务器也拒绝越权。
- 学员无需登录，由助教管理；公司内直接编辑成员、职位、名称和备注。
- 手机底部固定「主页 / 收益登记 / 学员登记 / 设置」；右上「助教 / 主办方 / 大屏」。
- 服务器保存收支，退出再登录、换设备不重置；初始化新一期保留上一期档案。

GitHub 保存的是源码。真实账号和数据库需要服务器运行，GitHub Pages 本身不能运行这些后端功能。根目录 `index.html` 是下文介绍的旧本地演示版本，不是联网入口。

---

用于七天商战活动的单文件网页。包含助教端、主办方端、收益申报终端、排名大屏与设置页，支持浅色和深色主题。

## 运行

下载本项目，双击 `index.html` 即可打开。无需安装依赖，也没有构建步骤。

主办方默认口令为 `8888`，可在「主办方端 → 数据管理」中修改。首次运行会载入示例活动；正式使用前，可通过「设置 → 初始化，开始新活动」清空示例数据并进入第 1 天。

## 功能

- 七天活动推进及进度显示。
- 学员、公司与老板／财务管理／员工职位管理。
- 助教收益登记、主办方审批与直接登记。
- 个人和公司收益统计、排名大屏轮播。
- 按职位比例进行最终结算。
- JSON 数据导出备份与导入恢复。
- 活动初始化和示例数据加载。
- 深浅色切换、自动保存外观偏好及手机布局适配。

## 数据与适用范围

当前版本是浏览器本地数据演示版。活动数据存储于 `localStorage`，不同设备、浏览器或网址之间不会自动同步。迁移活动时，应从原页面导出 JSON，在新页面导入。

「收益上传终端」目前使用本地申报流程；选择凭证照片不会把图片上传或保存到服务器。公司收益为所属成员已审批收益的汇总。主办方口令只用于前端界面的操作提示，不构成服务器端身份认证。

仓库中的学员和公司名称为示例数据，不包含用户浏览器中的真实活动记录。

## 修改源码

页面结构、样式和功能均在 `index.html` 内，使用文本编辑器即可修改。初始化会清空人员、公司、收益流水和结算结果，保留口令、分配规则和主题偏好。
